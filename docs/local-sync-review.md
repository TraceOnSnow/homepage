## 3. 元数据故障

本轮只在 WSL 发出有限的公开测试请求，响应保存在忽略的 `.cache/sync-validation/`，没有操作服务器：

| 来源 | 原始请求 | 正常适配器 |
| --- | --- | --- |
| Bangumi | 带／不带认证搜索均 200；缓存和非缓存详情均 200，非缓存为 MISS | 搜索 6 个候选，详情补全 ok |
| BGG | 带本地 Token 搜索 200，XML 包含作品；无 Token 为 401 | 搜索 8 个候选，详情仍 error，未达到完整验收 |

本地原始请求沿用 25 秒诊断超时；正常适配器仍使用现有 8 秒超时。两组都通过的 Bangumi 才能排除仅延长超时导致的假成功。BGG 详情在保守等待 120 秒后做了一次只读诊断：HTTP 200 但 XML items 为空。随后两个请求各间隔至少五秒：已知 Catan（ID 13）正常；首候选 ID 134277 去掉 type 过滤后正常，返回 boardgameexpansion。搜索将扩展包纳入候选，而现有详情固定 type=boardgame 将它过滤，导致适配器报 error。该本地问题与服务器旧报告的 Cloudflare 403 分开处理。

服务器旧报告的 403／522 是历史观测，本次没有重新核验服务器，也没有证明双方 Token 相同。不能由本地结果直接认定服务器已恢复、Key 相同或出口被封。搜索成功也不能代替详情和保存验收。
