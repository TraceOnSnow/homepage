# 文章列表封面

文章列表采用上方横幅。优先级为：文章手选封面 → 公开作品与文章的明确关联 → 通用封面池。不按标题猜作品，也不读取私人作品或正文。没有手选封面的游戏感想会复用作品图片；横图直接适配，竖图完整显示在同图模糊背景上，不拉伸、不截掉主体。此变化不替换文章正文页的主题背景或手选SEO图片。

## 管理通用图片

登录原后台后打开 **网站封面池**（`/admin/site-covers`）：

1. 原有21张图片可逐张勾选，也可以整体停用。
2. 用原生媒体窗口上传或选择喜欢的图片；在池中移除只取消选用，不删除媒体文件。
3. 保存后等待网站原有180秒静默期及构建完成。相同文章稳定使用同一张通用图，调整池成员时可能重新分配。

上传进池的图片会公开展示。至少保留一张可用图片；已删媒体会显示提示，需要移除或替换。同一时间另一个窗口保存会提示冲突，保留当前选择供核对，不覆盖他人的保存。未保存离开会提醒。

## 运行与兼容

配置保存在现有持久Media目录的`.cover-pool.json`，纳入原数据备份；不新增数据库字段或迁移。锁文件由内核管理，进程退出自动解锁。隐藏配置及锁文件不通过媒体路径公开。`GET /api/site-covers`只返回可公开的选图配置；修改需原管理员认证。

现有发布器将封面池和媒体更新时间与内容一起冻结，构建中变更会重新等待，构建失败保留旧站。旧后台404、旧快照以及全部所选图片失效分别有兼容处理；失效的空池临时回退原21图，不阻断其他文章更新。文件模式仍使用站点配置及原21图。

验证包括封面优先级、明确关系、稳定分配、冻结快照、管理员权限、并发保存与进程崩溃解锁、原生媒体上传选择、桌面/手机/无JS文章卡片。完整构建与浏览器在原CI执行；实际部署状态以部署回执为准。
