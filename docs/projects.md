# 首页项目展示

首页文章列表前展示项目卡片，顶栏仍只有首页、文章、媒体库、关于、友链。项目卡片沿用媒体库的封面、标题、圆角和悬停样式，使用横向封面框；简介下方的开发文章与媒体库感想共用 `ArticleNote`。

## 更新资料

项目资料暂时由 Git 中的 `src/data/projects.ts` 管理，不新增 Payload Collection 或数据库迁移。初始 5 条资料来自旧博客的 `src/data/projects.ts`，未重新判断项目开发状态，也未修改旧仓库。SteamGuess 截图复制自旧个人主页，其余项目缺少截图，先显示统一的字母占位封面。

- `slug`：稳定的项目标识。
- `title`、`description`：项目名称与简介。
- `url`：点击封面或标题时打开的项目／GitHub 地址。
- `cover`：可选的本地截图路径，文件放在 `public/img/projects/`。
- `article`：可选的已发布文章固定链接，不含 `/post/`。例如文章地址为 `/post/building-my-app` 时填写 `article: 'building-my-app'`。

文章从当前选定的 `CONTENT_SOURCE` 读取，不另存正文；标题和地址随正常构建更新。没有关联、文章不存在或尚未发布时不显示开发文章入口。初始项目没有可靠的对应开发文章，因此不填示例关联。

没有额外的项目详情页、浏览器 API 请求或复杂筛选。项目资料变更随代码部署生效，已关联文章的更新沿用文章发布流程；项目后台管理可在后续单独讨论。

## 暂时隐藏的功能

`config/site.yaml` 移除了周刊、歌单和写作室的顶栏入口，关闭周刊首页高亮与 `bgm.enabled`；`moments.enabled` 继续为 `false`。保留原文章、页面、编辑工具及歌单配置，不引入动态服务。需要恢复时再调整配置。
