# 项目展示

项目在独立的 `/projects` 页面展示（顶栏“项目”）。项目卡片沿用媒体库的封面、标题、圆角和悬停样式，使用横向封面框；简介下方的开发文章与媒体库感想共用 `ArticleNote`。

## 更新资料

项目资料由 Git 中的 `src/data/projects.ts` 管理，不新增 Payload Collection 或数据库迁移。`/projects` 分两部分：`featured: true` 的项目用详细卡片（左侧截图、右侧说明），其余放在下方“早期尝试”的紧凑封面网格。2026-11-21 起重写了项目说明，事实来自各仓库 README／设计文档和本人内容库笔记，找不到依据的内容不写。

- `slug`：稳定的项目标识。
- `title`、`description`：项目名称与一两句话简介，两种卡片都会显示。
- `url`：点击封面时打开的地址；以 `/` 开头的站内地址按当前语言生成链接并在本页打开，外部地址新开标签页。
- `cover`、`coverAlt`：可选的本地截图与替代文字，文件放在 `public/img/projects/`，使用 16:10 的 webp（约 1024×640，质量 78）。
- `featured`：是否作为详细卡片展示。
- `meta`：项目性质与时间，如“个人项目 · 2026.11 起”。
- `built`：做了什么，每条一句。
- `challenge`：最难的问题（`title`）与处理方式（`body`）。
- `stack`：技术栈标签。
- `links`：额外链接（在线地址、GitHub 等）。
- `article`：可选的已发布文章固定链接，不含 `/post/`。例如文章地址为 `/post/building-my-app` 时填写 `article: 'building-my-app'`。

截图只拍公开页面，不拍需要登录或带邀请凭证的页面。NanoParty 的截图来自仓库本地测试房间（测试玩家、模拟模型），SteamGuess 与媒体库截图来自线上公开页，HearthGen 用的是仓库 `results/` 中提交的生成原画。

文章从当前选定的 `CONTENT_SOURCE` 读取，不另存正文；标题和地址随正常构建更新。没有关联、文章不存在或尚未发布时不显示开发文章入口。

没有额外的项目详情页、浏览器 API 请求或复杂筛选。项目资料变更随代码部署生效，已关联文章的更新沿用文章发布流程。

`config/site.yaml` 移除了周刊、歌单和写作室的顶栏入口，关闭周刊首页高亮与 `bgm.enabled`；`moments.enabled` 继续为 `false`。保留原文章、页面、编辑工具及歌单配置，不引入动态服务。需要恢复时再调整配置。
