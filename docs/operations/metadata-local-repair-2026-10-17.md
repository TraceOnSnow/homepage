## 诊断日志

HTTP 层现在向现有进程日志输出 JSON 事件 `metadata-upstream`，包含来源、search／details、requestId、耗时、HTTP 状态、headers／body 阶段、错误类别、经过校验的 CF-Ray／缓存状态和 Retry-After 毫秒数。

不输出 URL、查询参数、请求体、搜索词、Cookie、Token、错误 HTML 或异常原文。异步上下文隔离并发来源，日志失败不会改变请求结果。`outcome=ok` 代表传输和正文读取／JSON 解析成功，不代表上游一定返回了有效作品；仍需检查 provider state 和候选／详情。

没有新增日志服务、重试、代理、DNS 改动或密钥轮换；已有 Docker 日志轮转继续负责保留策略。补丁部署后，可从现有 Payload 容器日志筛选 `metadata-upstream` 查看失败类别。
